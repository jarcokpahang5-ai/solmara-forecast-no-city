# Funniest Forecast for a City That Isn't

A one-line weather forecast for Glumbria, a city that does not exist: upside-down rain, gossiping winds, and a high of "just stay inside."

Built for the make.fun bounty "Funniest Forecast for a City That Isn't". `main.py` (pure Python 3 standard library) writes the single forecast line to `/output/entry.txt` and prints it to stdout.
